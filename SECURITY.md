# LegalDesk Pro – Security Notice

**Not production-ready. Synthetic data only.**

This portfolio demonstration has no login, authentication, per-record authorization,
encryption at rest, data retention policy, encrypted backup solution, security audit,
malware scanning, or hardened hosting configuration. Binding to localhost in the
start scripts is a *risk reduction*, not a complete security control.

Never upload actual privileged case records or personally identifying legal-client data.
Do not expose the server to the Internet or a shared network. No warranty of KVKK,
GDPR or bar association compliance is expressed or implied.

Before production use implement security architecture, least-privilege authorization,
password/session controls, CSRF defenses, access logging, document scanning,
secure encrypted storage and backups, lifecycle/retention policies, and independent
security and legal review.

If you discover a security weakness, do not post confidential information in public
GitHub issues. Contact the maintainer through GitHub privately.
